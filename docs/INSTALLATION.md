# Cài đặt Extension

## Chrome
1. Giải nén source code.
2. Truy cập `chrome://extensions`.
3. Bật Developer mode.
4. Chọn Load unpacked.
5. Chọn thư mục chứa `manifest.json`.

## Microsoft Edge
1. Truy cập `edge://extensions`.
2. Bật Developer mode.
3. Chọn Load unpacked.
4. Chọn thư mục chứa `manifest.json`.

Sau khi sửa source, quay lại trang Extensions và nhấn nút Reload trên thẻ extension. Tải lại trang HUSC để nạp content script mới.
